My Projects

This page showcases projects from my coursework and practical learning in Information Technology.

Smart Parking Gate Controller

I designed a finite-state-machine controller with defined states, input and output logic, and safety overrides. I documented its state transitions and tested its behavior under different operating and fault conditions.

Cisco Enterprise Network Design

I designed and configured a network in Cisco Packet Tracer using routers, switches, computers, and a server. I configured addressing, VLANs, routing, and network services, then tested connectivity and troubleshot configuration issues.

IT Support and Virtualization Lab

I created Windows and Linux virtual machines using VMware and VirtualBox to practise system administration and IT support. I worked on user accounts, permissions, and network settings, and documented solutions to simulated support problems.

AI Tool Evaluation Workshop

During an Ontario Tech University workshop, I tested Google AI tools using questions, supplied context, and linked tasks. I compared their outputs for accuracy and consistency as the tasks became more complex or included uncertain information.
